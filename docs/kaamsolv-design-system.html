Don't make a tool feel like software. Make it feel like help.

Every component below follows the same rule: show what's needed, hide what isn't, and reveal more only once the person has told you what they're trying to do.

Progressive disclosure

Start with one field. Add options only after the basics are done.

One brand, two shells

Public tools and the logged-in app share components — the app just adds a sidebar.

Light and dark, one identity

Dark mode changes the surfaces, never the brand hues.
